# 学习通伴学

一个面向学习通网页版的 Chrome 扩展。它会在当前框架中尝试连播视频，并提供本地单选题导入、判题和计分。

## 安装

1. 解压源码包，打开 Chrome 的 `chrome://extensions`。
2. 打开「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择源码中的 `extension` 文件夹。

## 使用

- **视频连播**：刷新课程页，手动播放第一段视频。视频自然播完后，扩展尝试播放同一框架中位于其后的下一段可见 HTML5 视频。如果浏览器要求手动播放，直接点击原播放器。课程按章节或框架分开放置视频时，需要手动切换。
- **题库练习**：点击扩展图标并打开本地题库，导入 `example-bank.json`。答题后点「判题」查看解析，完成全部题目后查看得分。替换题库或关闭页面会结束本轮练习。

题库采用 JSON 数组，每项包含 `question`（题干）、`options`（选项数组）、`answer`（从 0 开始的正确选项下标）和可选的 `explanation`（解析）。题库内容留在本地练习页面。

视频功能仅适用于同一框架中同时存在的标准 HTML5 视频。平台记录以播放器和课程页面实际显示为准。当前版本尚未在登录后的实际课程页面验证。
